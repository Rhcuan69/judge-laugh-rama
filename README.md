# Make the AI Judge Laugh

make.fun bounty entry — one joke about office life, one line, under 200
characters, written to be read aloud in one breath.

- `main.py` (pure Python standard library, no third-party packages)
  writes one line to `/output/entry.txt`.
- Deterministic: two runs produce byte-identical output.
- The joke: "I hit reply-all to ask everyone to stop hitting reply-all,
  and now forty-two colleagues agree with me."

Run it: `python3 main.py` (writes `/output/entry.txt`).
